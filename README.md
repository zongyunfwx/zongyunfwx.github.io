# zongyunfwx · AI 算法工程作品集

个人作品集网站，汇集自动驾驶、具身智能、深度学习、强化学习、导航与状态估计，以及嵌入式和桌面软件开发等方向的 21 个项目。

网站支持手机与桌面浏览，提供项目分类筛选、独立详情页、图片与视频展示，以及个人介绍、技术方向和联系方式。

12. 智能汽车竞赛：多传感器融合定位与自主导航

## 技术与预览

网站使用原生 HTML、CSS 和 JavaScript，通过 GitHub Pages 部署。首页位于 `index.html`，项目详情页位于 `projects/`，图片、视频和共享样式位于 `assets/`。

在项目根目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8000/ 即可预览。
