Qt 桌面宠物-动画渲染、交互设计与 Windows 部署

实现透明桌面窗口、序列帧动画、状态交互与 Windows 应用部署。

技术实践 演示视频 全部项目

技术实践

  • 基于 C++ / Qt Widgets 开发桌面宠物应用，实现透明无边框、窗口置顶与鼠标拖拽，结合系统托盘完成显示、隐藏及退出管理；
  • 设计基于 QTimer 与 QPainter 的序列帧动画模块，利用 QMap 管理 4 类动作资源，结合 Qt 元对象机制实现右键菜单与动画状态切换；
  • 通过 事件过滤器处理鼠标交互，使用 QRC 内嵌图片资源，完成 Windows Release 构建、动态库部署及单文件封装，实现免配置运行。
