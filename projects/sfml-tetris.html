俄罗斯方块-基于 C++ 和 SFML 的桌面游戏开发

完成方块生成、旋转碰撞、计分、音效与游戏存档恢复的桌面游戏。

技术实践

  • 基于 C++ 与 SFML 开发桌面俄罗斯方块游戏，构建 20×10 棋盘与 7 类方块，实现随机生成、移动旋转、自动下落及消行计分；
  • 采用二维数组维护棋盘状态，基于坐标变换与碰撞检测实现方块旋转、边界约束及落地判定，通过位置备份与回退处理无效操作；
  • 基于事件循环与时钟计时实现键鼠交互，支持加速下落、暂停及重新开始，集成下一方块预览、无边框窗口拖拽、背景音乐与消行音效；
  • 实现棋盘状态与分数的本地持久化及启动恢复，支持退出后继续游戏；完成 Visual Studio 工程配置与 SFML 集成，配置 Debug 调试及 Release 窗口模式。
